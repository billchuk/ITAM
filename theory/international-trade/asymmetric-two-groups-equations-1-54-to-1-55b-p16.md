# 《国际贸易应用模型》P16：非对称商品组（1.54）—（1.55b）逐式推导

> **教材**：刘文革、裴莹编著，《国际贸易应用模型》，清华大学出版社，2026 年 6 月第 1 版，ISBN 978-7-302-71633-4。  
> **章节**：第一章第三节，**三、非对称情形**；印刷页码 P16。  
> **本篇任务**：解释两类商品组之间完全替代、组内 CES 偏好及两种“单一商品组”候选均衡的全部五个变量。  
> **先修**：[P11 市场均衡（1.17）—（1.21）](market-equilibrium-equations-1-17-to-1-21-p11.md)；[P17 进入条件与角点最优（1.56）—（1.59）](asymmetric-entry-and-optimum-equations-1-56-to-1-59-p17.md)。

## 0. 记号与经济问题

两类差异化商品分别属于组 $`k=1,2`$，组内由 $`n_k`$ 个品种组成。第 $`k`$ 组内各企业具有相同固定成本 $`a_k>0`$、边际成本 $`c_k>0`$，CES 参数为 $`0<\rho_k<1`$。定义：

```math
\boxed{ \beta_k=\frac{1-\rho_k}{\rho_k}>0, \qquad \sigma_k=\frac1{1-\rho_k}=1+\frac1{\beta_k}>1. }
```

其中 $`x_{ki}`$ 表示第 $`k`$ 组的第 $`i`$ 个品种的消费量，$`p_{ki}`$ 是价格。同质商品 $`x_0`$ 的单价标准化为 1，预算为 $`I=1`$；外层 Cobb–Douglas 支出份额参数为 $`0<s<1`$。

- **组内**：CES，不同品种是不完全替代。
- **组间**：两组的 CES 复合数量直接相加，是**完全替代**，因而消费者在价格不同时可能只购买一组。
- **特别说明**：本篇先分别**假定另一组没有生产**，计算各组单独存在时的**候选**均衡；是否真能阻止另一组进入，须在 P17 进一步检查，不能由（1.55）直接断言两者都是纳什均衡。

## 1. （1.54）两层效用结构

定义两个组的 CES 复合数量：

```math
Y_1=\left(\sum_{i_1=1}^{n_1}x_{i_1}^{\rho_1}\right)^{1/\rho_1}, \qquad Y_2=\left(\sum_{i_2=1}^{n_2}x_{i_2}^{\rho_2}\right)^{1/\rho_2}.
```

原书的效用函数：

**式（1.54）**

```math
\boxed{ u=x_0^{1-s}\left\{ \left[\sum_{i_1=1}^{n_1}x_{i_1}^{\rho_1}\right]^{1/\rho_1} + \left[\sum_{i_2=1}^{n_2}x_{i_2}^{\rho_2}\right]^{1/\rho_2} \right\}^{s}. }
```

记 $`Y=Y_1+Y_2`$，则简写为：

$$u=x_0^{1-s}Y^s.$$

组内 CES 单位综合数量的最小支出（价格指数）分别为：

**式（A）**

```math
\boxed{ q_k=\left(\sum_{i=1}^{n_k}p_{ki}^{-1/\beta_k}\right)^{-\beta_k}, \quad k=1,2. }
```

因为组间 $`Y=Y_1+Y_2`$ 线性相加，对给定 $`Y`$ 的支出最小化问题是：

```math
\min_{Y_1,Y_2\ge0}\ q_1Y_1+q_2Y_2 \quad\text{s.t.}\quad Y_1+Y_2=Y.
```

所以：
- 若 $`q_1<q_2`$，最便宜的方案为 $`Y_1=Y,Y_2=0`$；
- 若 $`q_2<q_1`$，为 $`Y_2=Y,Y_1=0`$；
- 若 $`q_1=q_2`$，消费者在两组间无差异，可能存在多种分配。

这就是为什么要分别计算“仅第 1 组生产”与“仅第 2 组生产”的候选均衡。

## 2. 只有第 $`k`$ 组活动时：通用求解步骤

假定只有组 $`k`$ 存在，写 $`x_k,p_k,n_k`$ 为其对称企业产量、售价、企业数。

### 2.1 两阶段预算分配

外层效用为 $`u=x_0^{1-s}Y_k^s`$，预算：

$$x_0+q_kY_k=1.$$

Cobb–Douglas 内点最优时：

**式（B）**

$$\boxed{x_0=1-s,\qquad q_kY_k=s.}$$

对应对称企业：

**式（C）**

$$\boxed{n_kp_kx_k=s,\qquad q_k=p_kn_k^{-\beta_k}.}$$

### 2.2 CES dd 需求与企业加成

由前面固定弹性推导，单个企业在“单一品种对综合需求影响可忽略”的大品种数近似下面临

$$\varepsilon_{ki} =-\frac{1+\beta_k}{\beta_k}.$$

利润函数：

$$\pi_{ki}=(p_{ki}-c_k)x_{ki}-a_k.$$

利润最大化的一阶条件：

$$1+\frac{p_{ki}-c_k}{p_{ki}}\varepsilon_{ki}=0.$$

解得：

**式（D）**

$$\frac{p_k-c_k}{p_k}=\frac{\beta_k}{1+\beta_k}, \qquad \boxed{p_k=c_k(1+\beta_k)}.$$

### 2.3 自由进入零利润决定单企业规模

在自由进入、连续品种数的长期均衡近似下：

$$(p_k-c_k)x_k=a_k.$$

由 $`p_k-c_k=c_k\beta_k`$：

**式（E）**

$$\boxed{x_k=\frac{a_k}{c_k\beta_k}}.$$

### 2.4 部门预算决定企业数

由（C），$`\ n_kp_kx_k=s`$，故：

**式（F）**

```math
\begin{aligned} n_k &=\frac{s}{p_kx_k}\\ &=\frac{s}{c_k(1+\beta_k)\cdot a_k/(c_k\beta_k)}\\ &=\boxed{\frac{s\beta_k}{a_k(1+\beta_k)}}. \end{aligned}
```

这里的 $`n_k`$ 是连续变量近似结果；当企业必须取整数，需另行使用整数进入的利润不等式。推导（D）亦使用大品种数的需求近似，若计算出非常小的 $`n_k`$，相关公式的自洽性需要特别检查。

### 2.5 综合价格指数

**式（G）**

```math
\begin{aligned} q_k &=p_kn_k^{-\beta_k}\\ &=c_k(1+\beta_k) \left[\frac{s\beta_k}{a_k(1+\beta_k)}\right]^{-\beta_k}\\ &=\boxed{ c_k(1+\beta_k)^{1+\beta_k} \left(\frac{a_k}{s\beta_k}\right)^{\beta_k} }. \end{aligned}
```

### 2.6 单一商品组的总效用

由（B），$`x_0=1-s`$、$`Y_k=s/q_k`$：

**式（H）**

```math
\begin{aligned} u_k &=(1-s)^{1-s}(s/q_k)^s\\ &=\boxed{s^s(1-s)^{1-s}q_k^{-s}}. \end{aligned}
```

当外层参数 $`s`$ 固定、资源/收入单位相同，**哪个候选组的复合价格指数较低，哪个候选方案的间接效用就较高**。

## 3. （1.55a）仅组 1 存在

以上通用式（D）—（H）令 $`k=1`$，得到原书（1.55a）：

**式（1.55a）**

```math
\boxed{ \begin{aligned} \bar x_1&=\frac{a_1}{c_1\beta_1},& \bar x_2&=0,\\ \bar p_1&=c_1(1+\beta_1),\\ \bar n_1&=\frac{s\beta_1}{a_1(1+\beta_1)},\\ \bar q_1&=\bar p_1\bar n_1^{-\beta_1} =c_1(1+\beta_1)^{1+\beta_1} \left(\frac{a_1}{s\beta_1}\right)^{\beta_1},\\ \bar u_1&=s^s(1-s)^{1-s}\bar q_1^{-s}. \end{aligned} }
```

带横杠的变量表示**仅对应组生产时的候选均衡值**，不是两组同时生产的总量。

## 4. （1.55b）仅组 2 存在

令 $`k=2`$，完全对称地得到：

**式（1.55b）**

```math
\boxed{ \begin{aligned} \bar x_2&=\frac{a_2}{c_2\beta_2},& \bar x_1&=0,\\ \bar p_2&=c_2(1+\beta_2),\\ \bar n_2&=\frac{s\beta_2}{a_2(1+\beta_2)},\\ \bar q_2&=\bar p_2\bar n_2^{-\beta_2} =c_2(1+\beta_2)^{1+\beta_2} \left(\frac{a_2}{s\beta_2}\right)^{\beta_2},\\ \bar u_2&=s^s(1-s)^{1-s}\bar q_2^{-s}. \end{aligned} }
```

两组方程只需交换下标 $`1\leftrightarrow2`$；没有额外的隐含不对称条件。

## 5. 两种候选方案如何比较？

```math
\bar u_1>\bar u_2 \quad\Longleftrightarrow\quad \bar q_1<\bar q_2,
```

因为 $`s>0`$，$`q^{-s}`$ 随 $`q`$ 严格递减。

**但是福利排序不等于进入稳定性排序**。即便 $`\bar u_1>\bar u_2`$，也仍需检验一家第 2 组企业是否能以低于 $`\bar q_1`$ 的价格吸引所有差异化部门支出、并覆盖固定成本 $`a_2`$。这个检验由下篇（1.56）给出。

## 6. 条件总结与阅读注意

1. **（1.54）是效用设定**，不是由前面的 CES 模型推导出来；两组“完全替代”是该模型刻意使用的假设。
2. **（1.55a/b）是按每组单独存在求得的候选结果**；充分阻止异组进入需要（1.56）/（1.57）的条件。
3. **$`n_k`$ 连续近似与小企业定价近似**：数学上可列出表达式，但当 $`n_k`$ 很小时应重新考虑需求指数反馈和整数进入。
4. **福利只看 $`q_k`$** 的比较建立在两候选方案拥有相同收入规模、相同外层参数 $`s`$、同质商品价格相同的基础上。
5. 当 $`q_1=q_2`$ 时，组间完全替代导致消费者可能无差异，分配不再是唯一角点。
